## 1. Mandate

Iteration 3 makes the reconstruction *visible* and the epistemic surface *legible*, without touching the frozen spine:

- **Phase A — `challenge` affordance (engine-existing):** the ADR-011 free-chat already supports the `challenge` action ("interrogate a reconstruction/testimony line"). The literary surface exposes it as a collapsed, never-blocking command hint. Shipped in Iteration 2 UI.
- **Phase B — R3F reconstruction visual:** render the existing deterministic `buildReconstructionState` adapter as a Three.js fragment field. Read-only; carries the **Two-Chris gap** through visual grammar. No new epistemic logic.
- **Phase C — divergence alerts:** promote existing `visibleContradictions` into actionable, epistemic-framed alerts when a stronger (canonical) claim is in tension with a weaker (mythos) reconstruction claim. Additive field on the board payload; surfaced in the Consistency Board.

## 2. Visual Grammar (Phase B)

Deterministic boundary: `WorldState -> buildReconstructionState -> <ReconstructionScene>`. Same inputs → same scene (no `Math.random` in placement; drift uses time only).

| Source / status | Treatment | Meaning |
|---|---|---|
| canonical / inferred / observation | solid, cool white, settled | "real Chris bone" |
| reddit / author / compiled_event | solid, pale cyan | anchored to source |
| conversation (mythos) | stitched (wireframe, jitter, flicker), amber | woven from the reconstruction's delusions |
| belief / hypothesis / rumor (unsourced) | dim, drifting | unanchored |

Legend text (verbatim in UI): `■ real Chris bone (canonical)` · `□ stitched from mythos` · `· unanchored / drifting`.

The scene is **behind a toggle** (`.scene-toggle`) for performance — it mounts a WebGL canvas only when opened.

## 3. Divergence Alerts (Phase C)

- Computed in `buildInvestigationPayload` from `visibleContradictions`. For each, the contradicting fact node is classified by `kind` + `claimedBy`:
  - `strongerSource` = `canonical` when the fact/evidence node is canonical-tier; otherwise its `claimedBy`.
  - `weakerSource` = `mythos` when the contradicting node is `belief`/`claim`; otherwise its `kind`.
- Surfaced in the Consistency Board as a `DIVERGENCE ALERTS` section, rendered with `strongerSource ⊣ weakerSource · re-read source or challenge the claim` — never asserting world-truth, always pointing back to the source.
- Added to **both** `InvestigationPayload` shapes (lib `lib/core/investigation.ts` and the component-facing `components/investigation-payload.ts`) and unioned in `aggregateInvestigation`.

> **Note (smell, out of scope):** there are two parallel `InvestigationPayload` type definitions. They should be unified into one. That is a refactor, not an Iteration-3 change; flagged for a later ADR.
